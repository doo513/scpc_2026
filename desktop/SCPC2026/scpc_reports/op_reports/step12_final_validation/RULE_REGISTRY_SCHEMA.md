# Rule Registry Schema

Exact typed lookup keys are `(domain, operation, optional variant)`. Every RulePack references one role spec, information spec, blueprint, and registered constraints.

```json
{
  "blueprints": 14,
  "language_rules": 24,
  "ontology_types": 18,
  "ownership_fields": 17,
  "pair_constraints": 7,
  "record_adapters": 34,
  "rulepacks": 14
}
```
